# Мини-CRM «Объекты и задачи»

CRM для строительной компании на React, TypeScript и Supabase.

Установка: `npm install`
Настройка: скопируйте `.env.example` в `.env` и добавьте ключи Supabase.
База: примените миграцию, затем `supabase/seed.sql` после создания пользователей.
Запуск: `npm run dev`
Тесты: `npm test`
Сборка: `npm run build`
