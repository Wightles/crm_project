# описание для сдачи

Это мини-CRM для строительной компании. Постановщик управляет объектами и задачами, назначает исполнителей, принимает работу или возвращает её на доработку. Исполнитель видит только свои задачи, берёт их в работу и отправляет на проверку.

Доступ к данным ограничен политиками RLS в Supabase. Переходы статусов проверяются базой, а история изменений создаётся автоматически и не редактируется через API.

Самостоятельно выбраны роли `manager` и `executor`, отдельная карточка объекта и обязательный комментарий при возврате на доработку. Открытая регистрация отключена, пользователей нужно создать вручную в Supabase Auth.
